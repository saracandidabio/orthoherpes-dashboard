# Dashboard v8.1

Dashboard interativo para exploração e curadoria de dados de Orthoherpesviridae obtidos do NCBI, com visualizações de diversidade taxonômica, distribuição geográfica e temporal, hospedeiros, genes/CDS, proteínas hipotéticas e fluxo de curadoria da DNA polimerase viral. O projeto prioriza rastreabilidade, normalização auditável de metadados e preservação dos dados originais, com validações taxonômicas e funcionais apoiadas em referências do NCBI.
